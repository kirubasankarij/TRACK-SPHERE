---
description: how to run the TrackFlow application
---

This workflow guides you through starting the TrackFlow project.

### Step 1: Start Backend Infrastructure
Ensure **MongoDB** and **Redis** are running on your system.

### Step 2: Start the Server
Navigate to the `server` directory and run:
// turbo
```powershell
cd server
npm run dev
```

### Step 3: Start the Frontend
Navigate to the `client` directory and run:
// turbo
```powershell
cd client
npm run dev
```

### Step 4: Access the App
Open your browser and navigate to `http://localhost:3000` (or the port shown in the client terminal).
